## Confirmed defects

### High — Ogg packet assembly has no memory bound

- **Confidence:** High.
- **Evidence:** `D:\worktrees\ropus\20260822-REV-ROP-CDX@KILN-code-review-131329\ropus-tools-core\src\commands\info.rs:187-198,233-257,446-453,481-497,504-526` reads headers, tags, and audio through `ogg::PacketReader` before applying a size budget. `D:\worktrees\ropus\20260822-REV-ROP-CDX@KILN-code-review-131329\Cargo.lock:978-984` pins `ogg` 0.9.2. Its inspected `reading.rs:408-423,499-508` retains continuation fragments and allocates the complete packet before returning it.
- **Impact:** A crafted packet continued across the file can exhaust memory or abort `ropusinfo` before the header, tag, or audio validator can reject it. Every human mode and every query plan reaches packet assembly.
- **Concrete fix:** enforce header, tag, and audio byte budgets while consuming Ogg lacing, before continuation data is retained. Use the legal Opus audio ceiling and an explicit metadata policy. Cover exact-limit and over-limit continued packets.
- **Effort:** Medium to large.
- **Tracked as:** new Open bug `ROP-BUG-KIL-00059`. Coordinate its shared reader work with `ROP-BUG-KIL-00033` and Draft requirements `ROP-REQ-FLUX-00058`/`ROP-REQ-FLUX-00059`.

### High — reverse duration scan can trust an EOS page nested in payload

- **Confidence:** High.
- **Evidence:** `D:\worktrees\ropus\20260822-REV-ROP-CDX@KILN-code-review-131329\ropus-tools-core\src\container\ogg.rs:391-476` tests every candidate byte offset and validates only the candidate's local extent, serial, flags, and CRC. It does not prove a physical Ogg page boundary. `D:\worktrees\ropus\20260822-REV-ROP-CDX@KILN-code-review-131329\ropus-tools-core\src\commands\info.rs:204-207,462-465` trusts the returned granule.
- **Impact:** A CRC-valid page embedded inside a final payload can supply an attacker-chosen duration and bitrate. Dense candidates also repeat expensive CRC work.
- **Concrete fix:** derive duration only from a boundary-anchored physical page walk, with a CRC-valid nested-page regression and a candidate-density resource oracle.
- **Effort:** Medium.
- **Tracked as:** existing Open bug `ROP-BUG-KIL-00045`; no duplicate filed.

### Medium — strict queries accept malformed nonempty Opus packets

- **Confidence:** High.
- **Evidence:** `D:\worktrees\ropus\20260822-REV-ROP-CDX@KILN-code-review-131329\ropus-tools-core\src\container\ogg.rs:216-226` rejects only empty audio packets. `D:\worktrees\ropus\20260822-REV-ROP-CDX@KILN-code-review-131329\ropus-tools-core\src\commands\info.rs:461-498` trusts the EOS granule after that shallow check. Code-3 packets with missing or zero frame counts survive. Extended output at `:356-373` can print `frames=?` while inventing one frame with `unwrap_or(1)`.
- **Concrete fix:** validate complete Opus packet structure, lengths, padding, frame counts, and the 120 ms cap before scalar output. Keep extended duration unknown or reject the malformed packet.
- **Effort:** Medium.
- **Tracked as:** existing Open bug `ROP-BUG-KIL-00046`; no duplicate filed.

### Medium — metadata can come from another logical Ogg stream

- **Confidence:** High.
- **Evidence:** `D:\worktrees\ropus\20260822-REV-ROP-CDX@KILN-code-review-131329\ropus-tools-core\src\commands\info.rs:189-198,442-454` records the `OpusHead` serial but parses the next physical packet as `OpusTags` without checking that serial.
- **Impact:** A malformed or multiplexed file can report another stream's vendor/comments or reject an otherwise valid selected stream.
- **Concrete fix:** bind Head and Tags to one selected serial. Reject unsupported cross-stream pairing and share the validated header pair across collection plans.
- **Effort:** Small to medium.
- **Tracked as:** existing Open bug `ROP-BUG-KIL-00047`; no duplicate filed. General chained/multiplexed info remains explicitly out of scope in the signed design.

### Medium — normal pipelines can panic on closed stdout

- **Confidence:** High.
- **Evidence:** `D:\worktrees\ropus\20260822-REV-ROP-CDX@KILN-code-review-131329\ropus-tools-core\src\commands\info.rs:304-394,584-620` uses infallible `println!` for all human and machine output. `D:\worktrees\ropus\20260822-REV-ROP-CDX@KILN-code-review-131329\wrk_docs\2026.04.19 - HLD - opus-tools-parity.md:629-631` explicitly says users pipe extended output to `less` or `head`.
- **Impact:** When an early consumer closes the pipe, later writes panic and return an abnormal status rather than ending cleanly.
- **Concrete fix:** route output through fallible locked writers and define `BrokenPipe` as clean termination. Cover extended and large tag-query pipelines whose consumer exits early.
- **Effort:** Small to medium.
- **Tracked as:** the shared output root already filed as Open `ROP-BUG-KIL-00058`; its fix must include `ropusinfo`.

### Medium — fallback diagnostics can flood or block stderr

- **Confidence:** High.
- **Evidence:** `D:\worktrees\ropus\20260822-REV-ROP-CDX@KILN-code-review-131329\ropus-tools-core\src\commands\info.rs:220-255` prints one warning for every decoder failure on the unknown-granule fallback. `D:\worktrees\ropus\20260822-REV-ROP-CDX@KILN-code-review-131329\ropusinfo\src\main.rs:22-27,93-95` makes `--quiet` banner-only, so it does not bound these diagnostics.
- **Impact:** A malformed stream can generate output proportional to its packet count or block when stderr's reader stops draining.
- **Concrete fix:** cap or aggregate repeated packet warnings through an explicit diagnostic policy and emit one final error count.
- **Effort:** Small.
- **Tracked as:** the shared diagnostic-flood root already filed as Open `ROP-BUG-KIL-00057`; its fix must include this separate info collector.

### Medium — CLI parse failures bypass terminal-control escaping

- **Confidence:** High.
- **Evidence:** `D:\worktrees\ropus\20260822-REV-ROP-CDX@KILN-code-review-131329\ropusinfo\src\main.rs:48-55` calls Clap's exiting `get_matches()` path before the repository's escaped error reporter. Invalid argv can therefore reach Clap formatting first.
- **Concrete fix:** route every CLI through one non-exiting safe parse entry point that escapes untrusted error context while preserving trusted styling.
- **Effort:** Medium.
- **Tracked as:** existing Open bug `ROP-BUG-KIL-00054`; no duplicate filed.

### Medium — CLI child tests have no deadline

- **Confidence:** High.
- **Evidence:** `D:\worktrees\ropus\20260822-REV-ROP-CDX@KILN-code-review-131329\ropusinfo\tests\cli.rs:64-78,282-289,383-391,410-413` waits through `Command::output()` with no timeout, kill path, or guaranteed reap.
- **Impact:** A parser or info regression that loops or blocks wedges `cargo test -p ropusinfo` indefinitely.
- **Concrete fix:** share a timeout-aware child runner that kills and reaps on expiry. Prove the timeout path with a deliberately hanging helper child.
- **Effort:** Medium.
- **Tracked as:** existing Open bug `ROP-BUG-KIL-00055`; no duplicate filed.

### Low — playback-length rounding misses carries

- **Confidence:** High.
- **Evidence:** `D:\worktrees\ropus\20260822-REV-ROP-CDX@KILN-code-review-131329\ropus-tools-core\src\commands\info.rs:408-419` decomposes the unrounded duration, then rounds only the seconds field. At 48 kHz, one sample below an hour is `3599.999979` seconds and renders as `59m 60.00s`.
- **Concrete fix:** round total duration to centiseconds before decomposition, then derive normalized hours, minutes, and seconds. Cover one-sample-below minute and hour boundaries.
- **Effort:** Small.
- **Tracked as:** new Open bug `ROP-BUG-KIL-00060`.
