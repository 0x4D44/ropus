# Code review — `ropusdec/` decoder CLI

## Scope and method

- **Area:** `ropusdec/`
- **Baseline:** Deltic-supplied fresh `origin/main` worktree at `1c337e8751383e5e3a60009ce73e23283571edf0`. No fetch was performed under the transactional review contract.
- **Method:** static source, history, dependency-source, design, and ledger review only. No code, build, test, application, decoder, benchmark, or exploratory harness ran.
- **Lenses:** correctness, security, performance/scale, reliability, maintainability, test coverage, and a standing devil's advocate. Separate read-only reviewers covered each lens; the lead re-read every reported path and deduplicated the results.
- **Verification rule:** only source-confirmed, reachable defects survived. Existing records were reused. Refuted, duplicate, contract-ambiguous, or runtime-only claims were withheld.
- **Result:** two new defects filed Open. Two existing Open defects and two existing Draft requirements remain directly relevant. No new Draft requirement met the conservative capture threshold.

## Confirmed defects

### Medium — Clap parse errors bypass terminal-control escaping

- **Confidence:** High.
- **Evidence:** `D:\worktrees\ropus\20260822-REV-ROP-CDX@KILN-code-review-103628\ropusdec\src\main.rs:85-93` calls Clap `get_matches()`, which renders failures and exits before `prelude::run()` at `:129-132` can escape error text. `D:\worktrees\ropus\20260822-REV-ROP-CDX@KILN-code-review-103628\Cargo.lock:267-270` pins `clap_builder` 4.6.0; its inspected formatter interpolates invalid values and unknown arguments verbatim. Controls in an invalid `--gain` value or unknown dash-leading filename can therefore alter the terminal or forge stderr output.
- **Concrete fix:** centralize a safe `try_get_matches` entry point for all CLIs. Render parse errors through the reversible terminal-text policy while preserving only trusted formatter styling. Cover invalid values and unknown arguments containing C0/C1, OSC, CR/LF, and bidi controls.
- **Effort:** Medium.
- **Tracked as:** `ROP-BUG-KIL-00054`.

### Medium — CLI child processes have no execution deadline

- **Confidence:** High.
- **Evidence:** `D:\worktrees\ropus\20260822-REV-ROP-CDX@KILN-code-review-103628\ropusdec\tests\cli.rs:132-148,181-196,225-238,265-283,314-334,359-368` uses `wait_with_output()` or `output()` without a deadline, termination path, or timeout reap. A decoder regression that blocks or deadlocks can wedge `cargo test -p ropusdec` indefinitely.
- **Concrete fix:** use one timeout-aware child runner that captures diagnostics, kills and reaps on expiry, and has a deliberately hanging helper-child regression oracle.
- **Effort:** Medium.
- **Tracked as:** `ROP-BUG-KIL-00055`.

## Existing tracked findings confirmed in this path

- **Medium, High confidence — decode output has a publication race.** `D:\worktrees\ropus\20260822-REV-ROP-CDX@KILN-code-review-103628\ropus-tools-core\src\commands\decode.rs:122-134` checks aliases before a potentially long decode, then opens the regular destination at `:501-519` or through `audio/wav.rs:78-90,136-148`. Replacing the destination after preflight can redirect creation onto the input, and a late write failure destroys the prior destination. The correct fix is same-directory create-new temporary output plus atomic publication. Already Open as `ROP-BUG-KIL-00048`; no duplicate filed.
- **Medium, High confidence — default dither does not implement fractional TPDF noise.** `D:\worktrees\ropus\20260822-REV-ROP-CDX@KILN-code-review-103628\ropus-tools-core\src\commands\decode.rs:249,449-452` routes normal `ropusdec` i16 output through `audio/dither.rs:65-73`, whose one-bit draws produce integer `{-1,0,+1}` shifts and preserve the original fractional rounding bias. Already Open as `ROP-BUG-KIL-00044`; no duplicate filed.

## Actionable review-only findings

### Medium test gap — output oracles accept severely truncated success

- **Confidence:** High that the gap exists; no current decoder truncation was established.
- **Evidence:** `D:\worktrees\ropus\20260822-REV-ROP-CDX@KILN-code-review-103628\ropusdec\tests\cli.rs:148-170,196-214,238-255,283-305,334-353` checks exit status plus RIFF/WAVE magic, or only nonempty four-byte-aligned raw output. A successful implementation that emits a 12-byte WAV prefix or one arbitrary float can pass. The `--rate 44100` case never checks the WAV sample-rate field.
- **Concrete fix:** parse the WAV header and data chunk, require declared sizes to match delivered bytes, assert the expected one-second frame count and selected rate, and validate raw-float sample count and finite/non-silent content.
- **Effort:** Small to medium.
- **Tracking decision:** CR only. This is focused missing coverage, not a confirmed shipped-output defect.

### Low test gap — the no-color unit test bypasses production selection

- **Confidence:** High.
- **Evidence:** `D:\worktrees\ropus\20260822-REV-ROP-CDX@KILN-code-review-103628\ropusdec\src\main.rs:186-203` passes `ColorChoice::Never` directly. It does not exercise the production `prelude::no_color_requested()` decision at `:85-91`, so it remains green if `--no-color` stops selecting the tested branch.
- **Concrete fix:** extract an argument-injectable color-choice function or use a color-capable pseudo-terminal integration check that drives the real parser.
- **Effort:** Small.
- **Tracking decision:** CR only. Production behavior is currently wired correctly.

### Low maintainability — small wrapper drift remains

- **Confidence:** High.
- **Evidence:** `D:\worktrees\ropus\20260822-REV-ROP-CDX@KILN-code-review-103628\ropusdec\Cargo.toml:9-12` declares unused direct dependency `anyhow`. `D:\worktrees\ropus\20260822-REV-ROP-CDX@KILN-code-review-103628\ropusdec\src\main.rs:135-149` duplicates gain-range validation from the shared core and `ropusplay`. Test setup and manual cleanup repeat throughout `ropusdec/tests/cli.rs:23-105,132-353`.
- **Concrete fix:** remove the unused dependency; share the gain-range policy without losing early Clap diagnostics; introduce a small local process runner and drop-based temporary-file guard when addressing the confirmed test bugs.
- **Effort:** Small.
- **Tracking decision:** CR only. These are narrow cleanups, not standalone durable requirements.

## Not reported (why)

- **Refuted:** raw f32 data cannot currently contain the ASCII `RIFF` or `WAVE` four-byte window checked at `ropusdec/tests/cli.rs:300-305`. Every possible alignment would place a marker byte in an IEEE-754 high-byte position incompatible with normalized decoder samples. The oracle is coupled to the current normalized-output contract, but it is not a present false-failure defect.
- **Refuted:** one-byte Opus audio packets are not inherently malformed; valid DTX packets can have that shape.
- **Refuted:** typed banner/stdout routing, gain/rate/loss bounds, EOS trimming, header validation, empty-packet rejection, quiet reporting, and regular command error-chain escaping are present in the latest tree.
- **CR only:** `ropusdec/Cargo.toml` does not state `publish = false`, while `build.rs:1` imports shared source outside the crate directory. Project reports describe CLI crates as unpublished, but the signed CLI-split design did not establish a package-support contract. Enforce `publish = false` if that policy is intended; do not claim a packaging failure without a package check.
- **UNVERIFIED:** exact runtime impact of per-sample buffered writes and metadata size was not measured. Source establishes their shape, not a material performance regression beyond the existing bounded-streaming requirement.
