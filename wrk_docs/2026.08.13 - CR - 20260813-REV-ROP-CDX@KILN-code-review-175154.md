# Code review — `tools/`

- **Date:** 2026-08-13
- **Assigned area:** `tools/`
- **Baseline:** `24a1adc2771233d78d467085a44b1fcccb09440a`
- **Mode:** static, read-only review. No fetch, build, application, test,
  benchmark, fuzzer, or exploratory harness ran.

## Outcome

This pass confirmed fourteen defects: six High and eight Medium. The dominant
risk is false-green development automation. Several tools can skip required
work, lose child-process failures, or persist stale state while reporting
success. Two autonomous fixers also stage the whole worktree, which can capture
unrelated work or secrets.

Seven review roles covered correctness, security, performance/scale,
reliability, maintainability, test coverage, and implicit assumptions. Every
finding below survived a separate source-level challenge. No finding depends on
running the application or treating an unexecuted check as evidence.

## Confirmed findings

### CR-TOOLS-01 — High: autonomous checkpoints stage unrelated workspace files

- **Confidence:** High.
- **Location:**
  `D:\worktrees\ropus\20260813-REV-ROP-CDX@KILN-code-review-175154\tools\bisect_fix.py:283`,
  `D:\worktrees\ropus\20260813-REV-ROP-CDX@KILN-code-review-175154\tools\trace_fix.py:454`.
- **Evidence:** both loops run `git add -A` from the repository root, ignore
  both Git return codes, then log a successful checkpoint.
- **Impact:** a periodic checkpoint can commit another agent's edits,
  generated artifacts, or accidentally unignored secrets. A refused commit is
  also reported as successful.
- **Concrete fix:** remove implicit commits, or require a dedicated task
  worktree and stage an explicit path allowlist. Check and report every Git
  result.
- **Regression oracle:** create unrelated tracked and untracked sentinels, run
  the checkpoint seam, and prove neither is staged while a forced commit error
  returns nonzero.
- **Effort:** Small to medium.
- **Tracked as:** `ROP-BUG-KILN-00001`.

### CR-TOOLS-06 — Medium: the legacy seed generator shifts config into PCM

- **Confidence:** High.
- **Location:**
  `D:\worktrees\ropus\20260813-REV-ROP-CDX@KILN-code-review-175154\tools\generate_fuzz_seeds.py:119`;
  live parser at
  `D:\worktrees\ropus\20260813-REV-ROP-CDX@KILN-code-review-175154\tests\fuzz\fuzz_targets\fuzz_encode.rs:124`.
- **Evidence:** the generator emits a six-byte encode header. Current encode,
  roundtrip, and safety targets require eight bytes and interpret bytes 6–7 as
  VBR/FEC and DTX/loss controls.

  and compare all configuration fields plus the first PCM samples to the
  generator request.
- **Effort:** Small.
- **Tracked as:** `ROP-BUG-KILN-00006`.

### CR-TOOLS-08 — High: the fuzz runner reports all clear after child failure

- **Confidence:** High.
- **Location:**
  `D:\worktrees\ropus\20260813-REV-ROP-CDX@KILN-code-review-175154\tools\fuzz_run.sh:384`,
  `:408`, `:423`; unused option at `:134`.

### CR-TOOLS-09 — Medium: long fuzz launchers hide failures and trust duration arithmetic

- **Confidence:** High.
- **Location:**
  `D:\worktrees\ropus\20260813-REV-ROP-CDX@KILN-code-review-175154\tools\overnight_fuzz_launch.sh:16`,
  `:94`, `:119`;
  `D:\worktrees\ropus\20260813-REV-ROP-CDX@KILN-code-review-175154\tools\fuzz_24h_launch_v2.sh:20`,
  `:88`, `:123`.
- **Evidence:** both scripts discard individual background statuses and print
  completion after an unchecked `wait`. They also evaluate an unvalidated
  positional duration through recursive Bash arithmetic expansion.
- **Impact:** immediately failed workers can yield a successful campaign. A
  wrapper that passes untrusted duration text also exposes command execution
  during arithmetic evaluation.
- **Concrete fix:** validate a bounded decimal duration before any arithmetic,
  retain every PID, wait each one, and return nonzero with a per-target failure
  summary.
- **Regression oracle:** fake mixed worker outcomes and malicious/non-numeric
  duration strings; no payload may execute and any failed worker must fail the
  launcher.
- **Effort:** Small to medium.
- **Tracked as:** `ROP-BUG-KILN-00009`.

  campaign policy. The Draft requirement concerns target discovery drift, not
  the chosen counts.

### Unverified

- Direct archive extraction may permit absolute, parent, or symlink members.
  The IETF and model archives are hash-pinned, and this pass did not establish
  the foobar2000 archive's member layout. Hold until the trust and extractor
  contracts are checked directly.
- Build/test diagnostics are interpolated into fully privileged agent prompts.
  The injection path exists, but the intended trust boundary for these legacy
  local automation tools is not documented, so no security defect was filed.
- Parallel coordinator workers iterate and mutate shared dictionaries. A
  possible `dict changed size during iteration` failure remains unverified
  without establishing the exact interleaving.
- The PGO training loop ignores failed roundtrips. Its reporting is misleading,
  but profile merging may fail later when no usable data exists. The filed PGO
  bug owns the stronger current measurement failure.
