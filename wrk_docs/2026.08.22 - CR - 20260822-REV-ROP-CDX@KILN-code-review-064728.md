# Code review — `ropus-fb2k/`

- **Pass:** `20260822-REV-ROP-CDX@KILN-code-review-064728`

- **Baseline:** Deltic-supplied fresh worktree at `3e0f6c1cda93`
- **Method:** static review only, with correctness, security, performance/scale, reliability, maintainability, test-coverage, and devil's-advocate lenses
- **Not run:** the application, builds, tests, and exploratory comparison harness

## Result

Ten shipped defects were independently confirmed and filed. The highest risks are unbounded hostile-input allocation, a boundary-blind and potentially quadratic duration scan, undefined behavior at two C callback/API boundaries, and an unbounded seek index. One consolidated Draft requirement records durable test-oracle debt. No source file was changed.

RFC checks use the primary [Ogg Opus specification, RFC 7845](https://www.rfc-editor.org/rfc/rfc7845.txt). It requires bounded resource use, treats zero-octet audio packets as malformed, defines the R128 grammar, and warns specifically about quadratic end-of-stream scans. The FFI length finding also follows the documented safety requirements of [`slice::from_raw_parts_mut`](https://doc.rust-lang.org/std/slice/fn.from_raw_parts_mut.html).

## Requirements and technical debt

- `ROP-REQ-KIL-00043` — give `ropus-fb2k` independent cross-boundary test oracles. It consolidates four durable gaps: position-distinguishable seek fixtures, an independent C-reference decode comparison, a C-header ABI probe, and normal-gate execution of panic-safety coverage.
- Existing Draft `ROP-REQ-FLUX-00041` already covers centralizing validated Ogg page metadata parsing. No duplicate requirement was raised; it is relevant to the long-term fix for `ROP-BUG-KIL-00034`.

## Report-only observations

- `ropus-fb2k/include/ropus_fb2k.h:51-55` advertises `OPEN_INFO_ONLY`, while `ropus-fb2k/src/reader.rs:307-310` ignores all flags. The HLD says this is accepted for forward compatibility, so this is a header clarity issue, not a shipped behavior bug.
- `ropus-fb2k/src/tags.rs:47-52` says `ParsedTags::iter` skips filtered keys, but filtering occurs only at `ropus-fb2k/src/lib.rs:350-356`.
- `ropus-fb2k/src/error.rs:69-76` describes a last-error pointer lifetime that is shorter in practice because successful calls clear the backing string.
- `ropus-fb2k/src/reader.rs:1081-1091` computes nominal bitrate from the entire physical file, so trailing junk or later chains inflate the bitrate for the selected first stream. Chained playback itself is explicitly out of scope.

## Not reported as defects

- **Post-tags packet loss — refuted.** RFC 7845 requires the comment header to finish its page, so a conforming file cannot place an audio packet after it on that page. `PacketReader::into_inner()` therefore does not discard conforming audio at this boundary.
- **Concurrently multiplexed Ogg support — held out of scope.** The implementation would bind foreign tags or stop on a foreign packet, but RFC 7845 says such containers are not strictly `.opus` files and does not recommend the `.opus` extension. The malformed cross-stream header acceptance remains covered by `ROP-BUG-KIL-00042`.
- **CRC validation alone proves page provenance — refuted.** A nested fake page and its containing outer page can both carry valid CRCs; the candidate must also be anchored to the physical page sequence.
- **Callback panic escape — refuted.** Foreign C++ callbacks catch their own exceptions, while Rust panics do not originate in those callbacks. The confirmed issue is handle reentrancy, not unwinding.
- **ABI layouts are already wrong — unverified.** Static inspection found no concrete layout mismatch. Independent ABI coverage is tracked in `ROP-REQ-KIL-00043` instead.
- **EOS padding, transactional seek rollback, fixed scratch reuse, and cached-size handling — refuted.** The inspected code contains the required clamps, rollback state, reuse, and explicit design choices.
