# Code review — `ropus/` codec core

## Scope and method

- **Area:** `ropus/`
- **Baseline:** latest reachable `origin/main` at `58ee4f20a1d8188094510ed1177353974231045c`
- **Method:** static source review only. No build, tests, application, benchmark, or exploratory harness ran.
- **Lenses:** correctness, security, performance/scale, reliability, maintainability, test coverage, and devil's advocate.
- **Result:** seven confirmed defects filed Open; two structural findings captured as Draft requirements.

## Confirmed defects

### High — safe public DSP helpers can cause undefined behavior

- **Confidence:** High
- **Evidence:** `/Users/md/language/ropus/ropus/src/silk/common.rs:433` accepts safe slices and caller-supplied dimensions, then uses the unchecked-indexing macro from `/Users/md/language/ropus/ropus/src/lib.rs:227`. A short signal or coefficient slice reaches `get_unchecked`, so the failure is undefined behavior rather than a bounds panic.
- **Concrete fix:** validate every slice and dimension invariant before the first unchecked access. Internalize helpers that are not intended as public APIs, or mark genuinely caller-unsafe entry points `unsafe fn` with complete safety contracts. Audit every public `uc!`, `uc_set!`, and `uc_mut!` entry point.
- **Effort:** Medium.
- **Tracked as:** `ROP-BUG-FLUX-00007`.

### Medium — multistream constructors panic on undersized configuration slices

- **Confidence:** High
- **Evidence:** `/Users/md/language/ropus/ropus/src/opus/multistream.rs:915` and `:1611` index `mapping[i]` for every channel without checking `mapping.len()`. `/Users/md/language/ropus/ropus/src/opus/multistream.rs:2379` trusts the declared demixing-matrix size instead of the actual byte-slice length.
- **Concrete fix:** reject short mapping and matrix slices with `OPUS_BAD_ARG` before indexing. Use checked arithmetic for matrix dimensions and cover empty, short, exact, and longer slices.
- **Effort:** Small.
- **Tracked as:** `ROP-BUG-FLUX-00008`.

### Medium — projection encode/decode casts negative frame sizes before validation

- **Confidence:** High
- **Evidence:** `/Users/md/language/ropus/ropus/src/opus/multistream.rs:2263` and `:2415` cast `frame_size` to `usize` while sizing temporary buffers. A negative value becomes huge before the underlying codec can return `OPUS_BAD_ARG`.
- **Concrete fix:** reject non-positive and unsupported frame sizes before any cast, multiplication, or allocation. Validate the corresponding PCM/output slice lengths at the same boundary.
- **Effort:** Small.
- **Tracked as:** `ROP-BUG-FLUX-00009`.

### Medium — multistream decoder setters bypass validation and state propagation

- **Confidence:** High
- **Evidence:** `/Users/md/language/ropus/ropus/src/opus/multistream.rs:1966` through `:1992` call raw `ms_set_*` helpers and always return `OPUS_OK`. The helpers at `/Users/md/language/ropus/ropus/src/opus/decoder.rs:1582` through `:1592` skip gain/complexity validation. Valid complexity also fails to reach `CeltDecoder::set_complexity`, unlike `/Users/md/language/ropus/ropus/src/opus/decoder.rs:1518`.
- **Concrete fix:** fan out through the validated `OpusDecoder` setters, reject phase-inversion values outside `0..=1`, stop at the first error, and prove CELT state changes with the wrapper state.
- **Effort:** Small, including focused CTL tests.
- **Tracked as:** `ROP-BUG-FLUX-00010`.

### Medium — multistream expert frame duration accepts invalid values

- **Confidence:** High
- **Evidence:** `/Users/md/language/ropus/ropus/src/opus/multistream.rs:1524` stores every `i32` and returns no status. `/Users/md/language/ropus/ropus/src/opus/encoder.rs:3975` correctly accepts only `OPUS_FRAMESIZE_ARG` or defined 2.5–120 ms values.
- **Concrete fix:** apply the single-stream validation before mutation and return the matching Opus status code. Add lower/upper boundary and invalid-value tests.
- **Effort:** Small.
- **Tracked as:** `ROP-BUG-FLUX-00011`.

### Medium — multistream reset retains neural PLC history

- **Confidence:** High
- **Evidence:** `/Users/md/language/ropus/ropus/src/opus/multistream.rs:2000` routes reset through `/Users/md/language/ropus/ropus/src/opus/decoder.rs:1602`. That helper resets framing, SILK, and CELT state but omits the `lpcnet.reset()` performed by the canonical reset at `/Users/md/language/ropus/ropus/src/opus/decoder.rs:608`.
- **Concrete fix:** delegate the multistream path to the canonical reset or add the same LPCNet runtime reset while preserving loaded model weights. Add a reset/reuse regression that dirties FEC, analysis, and GRU state first.
- **Effort:** Small.
- **Tracked as:** `ROP-BUG-FLUX-00012`.

### Medium — extension parsers trust counts beyond their Rust slices

- **Confidence:** High
- **Evidence:** `/Users/md/language/ropus/ropus/src/opus/repacketizer.rs:652` trusts `nb_extensions` instead of `extensions.len()` before indexing at `:675`. `/Users/md/language/ropus/ropus/src/opus/extensions.rs:104` accepts negative per-frame counts into a wrapping prefix sum; `:132` through `:136` can then cast a negative index or exceed the output slice.
- **Concrete fix:** validate `0 <= len <= data.len()`, frame counts, non-negative checked prefix sums, and declared capacity against `extensions.len()`. Return `OPUS_BAD_ARG` or `OPUS_BUFFER_TOO_SMALL` without unwinding.
- **Effort:** Small to medium.
- **Tracked as:** `ROP-BUG-FLUX-00013`.

## Confirmed structural findings

### Medium technical debt — DRED reconstruction remains stranded behind stubs

- **Confidence:** High.
- **Evidence:** `/Users/md/language/ropus/ropus/src/opus/dred.rs:228`, `:249`, and `:270` still return `OPUS_UNIMPLEMENTED`, while `/Users/md/language/ropus/ropus/src/dnn/fargan.rs` now contains the synthesis implementation their comments awaited.
- **Concrete fix:** complete DRED-to-PCM rendering at the `OpusDecoder` seam, share the existing FARGAN model/load path, and cover i16, i24, and f32 parity.
- **Effort:** Large.
- **Tracked as:** Draft requirement `ROP-REQ-FLUX-00014`.

### Medium technical debt — real-time paths allocate repeatedly per frame

- **Confidence:** High for the static allocation count; runtime impact is **UNVERIFIED** because this pass did not benchmark.
- **Evidence:** each FARGAN subframe allocates five direct buffers in `/Users/md/language/ropus/ropus/src/dnn/fargan.rs:659` through `:757`, six GRU buffers, five GLU buffers, and one convolution buffer through `/Users/md/language/ropus/ropus/src/dnn/core.rs:630` through `:765`. Four subframes plus conditioning therefore allocate at least 69 vectors per 10 ms frame. CELT silence/prefilter work and float/i24 conversion wrappers also allocate per call at `/Users/md/language/ropus/ropus/src/celt/encoder.rs:2353`, `/Users/md/language/ropus/ropus/src/opus/encoder.rs:1709`, and `/Users/md/language/ropus/ropus/src/opus/decoder.rs:1372`.
- **Concrete fix:** add bounded state-owned scratch buffers or fixed arrays while preserving operation order and bit-exact output. Measure allocator count and latency before setting an acceptance threshold.
- **Effort:** Large.
- **Tracked as:** Draft requirement `ROP-REQ-FLUX-00015`.

## Not reported

- **Refuted:** `/Users/md/language/ropus/ropus/src/dnn/lpcnet.rs:1922` returns success after parse-only loading, but its documentation explicitly defines that staged contract and says the model remains unpopulated. The missing population work is not an accidental defect in this pass.
- **Refuted:** the mono-only DRED assertion is gated by `/Users/md/language/ropus/ropus/src/opus/encoder.rs:3904`, which rejects stereo DRED duration before the assertion is reachable.
- **Refuted:** the multistream lookahead difference at `/Users/md/language/ropus/ropus/src/opus/multistream.rs:1536` is explicitly preserved as the historical aggregate contract.
- **Held, not confirmed:** three single-byte packet-query helpers panic on an empty slice. They intentionally mirror C helpers that require a TOC byte, and this pass did not establish a compatible fallible return contract or a production path that passes an empty packet.
- **Not defects:** fixed-point wrapping, narrowing, and C-shaped loops were not reported without a source-confirmed out-of-domain caller or parity mismatch.

## Coverage handoff

All other ledger areas remain never reviewed. The next bounded pass should review `capi/` because it is the highest-risk remaining boundary: it translates external C pointers and lengths into the safe Rust codec.

# Code review — `capi/` C ABI adapter

## Scope and method

- **Area:** `capi/`
- **Baseline:** latest reachable `origin/main` at `1bef39ed13b1a39f4568e07638df4e9db0e53960`
- **Method:** static source review only. No build, tests, application, benchmark, conformance binary, or exploratory harness ran.
- **Lenses:** correctness, security, performance/scale, reliability, maintainability, test coverage, and devil's advocate.
- **Scope boundary:** `/Users/md/language/ropus/capi/src/lib.rs:1` defines this crate as a dev-only adapter for the xiph conformance tests, not a general libopus replacement. Deliberate test-only compatibility concessions were not filed as defects.
- **Result:** three confirmed defects filed Open. No design finding met the bar for a Draft requirement.

## Confirmed defects

### Medium — multistream decoder complexity CTLs are unreachable

- **Confidence:** High
- **Evidence:** the vendored API says decoder CTLs may be applied to a multistream decoder at `/Users/md/language/ropus/tests/conformance/include/opus_multistream.h:61`. The C dispatcher at `/Users/md/language/ropus/capi/src/ctl_shim.c:422` omits `OPUS_SET_COMPLEXITY_REQUEST`, and its getter switch at `:427` omits `OPUS_GET_COMPLEXITY_REQUEST`; both fall through at `:462`. The Rust dispatcher also omits them at `/Users/md/language/ropus/capi/src/ctl.rs:677` and `:708`, despite the underlying methods at `/Users/md/language/ropus/ropus/src/opus/multistream.rs:1988`.
- **Concrete fix:** route request codes 4010 and 4011 through both dispatch layers. Validate `0..=10` before mutation, return the first stream's value, and add focused C-driven valid/invalid set/get coverage.
- **Effort:** Small.
- **Tracked as:** `ROP-BUG-FLUX-00016`.

### Medium — C constructors abort instead of returning allocation failure

- **Confidence:** High
- **Evidence:** `/Users/md/language/ropus/capi/src/lib.rs:82` exports `OPUS_ALLOC_FAIL`, but handle allocators call `std::alloc::handle_alloc_error` at `/Users/md/language/ropus/capi/src/encoder.rs:49`, `/Users/md/language/ropus/capi/src/decoder.rs:78`, `/Users/md/language/ropus/capi/src/ms_encoder.rs:39`, `/Users/md/language/ropus/capi/src/ms_decoder.rs:34`, `/Users/md/language/ropus/capi/src/projection.rs:59`, and `/Users/md/language/ropus/capi/src/repacketizer.rs:72`. That path aborts; the unwind-only guard at `/Users/md/language/ropus/capi/src/lib.rs:105` cannot translate it. `Box` and `Vec` construction add more infallible allocation sites.
- **Concrete fix:** make all constructor allocations fallible, release partial state on failure, commit output parameters only after complete initialization, and return `NULL` or the matching status with `OPUS_ALLOC_FAIL`.
- **Effort:** Large.
- **Tracked as:** `ROP-BUG-FLUX-00017`.

### Low — exported version string is stale

- **Confidence:** High
- **Evidence:** `/Users/md/language/ropus/capi/Cargo.toml:3` declares `0.2.2`, while `/Users/md/language/ropus/capi/src/lib.rs:122` still embeds `mdopus-capi-0.1.0`; `/Users/md/language/ropus/capi/src/lib.rs:154` returns that literal to C callers.
- **Concrete fix:** derive the NUL-terminated string from `CARGO_PKG_VERSION` or generated build metadata. Add an assertion that ties the exported value to the manifest version.
- **Effort:** Extra small.
- **Tracked as:** `ROP-BUG-FLUX-00018`.

## Not reported

- **Refuted as defects under the stated scope:** copied single-stream handles intentionally alias one leaked Rust state, while multistream and projection handles intentionally advertise padded caller storage. `/Users/md/language/ropus/capi/src/decoder.rs:3` and `/Users/md/language/ropus/capi/src/lib.rs:34` document this conformance-only compromise. It would not satisfy a general libopus state-copy contract, but this crate explicitly disclaims that role.
- **Refuted as a defect under the stated scope:** `/Users/md/language/ropus/capi/src/projection.rs:385` quantizes float PCM before projection mixing. The module explicitly limits this path to overflow-regression length checks and records the reference-order divergence at `:8`.
- **Refuted as a defect:** no-op destruction and reinitialization leaks are deliberate for short-lived tests that copy, poison, and cross allocator boundaries; `/Users/md/language/ropus/capi/src/lib.rs:46` explains the choice.
- **Refuted as actionable performance debt:** extension parse/generate allocates on each iteration at `/Users/md/language/ropus/capi/src/extensions.rs:144`, `:260`, and `:325`, but the 100-million-cycle oracle completed inside its established 600-second budget, recorded at `/Users/md/language/ropus/wrk_journals/2026.04.18 - JRN - official-test-suite.md:205`. Runtime improvement is **UNVERIFIED** because this pass did not benchmark.
- **CR-only maintenance notes:** CTL request literals are duplicated between `/Users/md/language/ropus/capi/src/ctl.rs:21` and `/Users/md/language/ropus/capi/src/ctl_shim.c:21`, but they currently match and the end-to-end conformance route is intended to expose drift. `/Users/md/language/ropus/capi/src/lib.rs:84` also lists four CTLs as unimplemented even though their dispatch now exists.
- **Held, not confirmed:** a caught constructor panic can return `NULL` with stale output parameters, but this pass did not establish a valid-input panic trigger. The allocation-abort path is the narrower source-confirmed defect filed above.
- **Out of area:** the test-coverage lens raised hypotheses in `full-test/` and `tests/conformance/`. They were not promoted from this `capi/` pass.
