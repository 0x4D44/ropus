# Code review — `ropus/` codec core

## Scope and method

- **Area:** `ropus/`
- **Baseline:** latest reachable `origin/main` at `58ee4f20a1d8188094510ed1177353974231045c`
- **Method:** static source review only. No build, tests, application, benchmark, or exploratory harness ran.
- **Lenses:** correctness, security, performance/scale, reliability, maintainability, test coverage, and devil's advocate.
- **Result:** seven confirmed defects filed Open; two structural findings captured as Draft requirements.

## Confirmed defects

### High — safe public DSP helpers can cause undefined behavior

- **Confidence:** High
- **Evidence:** `/Users/md/language/ropus/ropus/src/silk/common.rs:433` accepts safe slices and caller-supplied dimensions, then uses the unchecked-indexing macro from `/Users/md/language/ropus/ropus/src/lib.rs:227`. A short signal or coefficient slice reaches `get_unchecked`, so the failure is undefined behavior rather than a bounds panic.
- **Concrete fix:** validate every slice and dimension invariant before the first unchecked access. Internalize helpers that are not intended as public APIs, or mark genuinely caller-unsafe entry points `unsafe fn` with complete safety contracts. Audit every public `uc!`, `uc_set!`, and `uc_mut!` entry point.
- **Effort:** Medium.
- **Tracked as:** `ROP-BUG-FLUX-00007`.

### Medium — multistream constructors panic on undersized configuration slices

- **Confidence:** High
- **Evidence:** `/Users/md/language/ropus/ropus/src/opus/multistream.rs:915` and `:1611` index `mapping[i]` for every channel without checking `mapping.len()`. `/Users/md/language/ropus/ropus/src/opus/multistream.rs:2379` trusts the declared demixing-matrix size instead of the actual byte-slice length.
- **Concrete fix:** reject short mapping and matrix slices with `OPUS_BAD_ARG` before indexing. Use checked arithmetic for matrix dimensions and cover empty, short, exact, and longer slices.
- **Effort:** Small.
- **Tracked as:** `ROP-BUG-FLUX-00008`.

### Medium — projection encode/decode casts negative frame sizes before validation

- **Confidence:** High
- **Evidence:** `/Users/md/language/ropus/ropus/src/opus/multistream.rs:2263` and `:2415` cast `frame_size` to `usize` while sizing temporary buffers. A negative value becomes huge before the underlying codec can return `OPUS_BAD_ARG`.
- **Concrete fix:** reject non-positive and unsupported frame sizes before any cast, multiplication, or allocation. Validate the corresponding PCM/output slice lengths at the same boundary.
- **Effort:** Small.
- **Tracked as:** `ROP-BUG-FLUX-00009`.

### Medium — multistream decoder setters bypass validation and state propagation

- **Confidence:** High
- **Evidence:** `/Users/md/language/ropus/ropus/src/opus/multistream.rs:1966` through `:1992` call raw `ms_set_*` helpers and always return `OPUS_OK`. The helpers at `/Users/md/language/ropus/ropus/src/opus/decoder.rs:1582` through `:1592` skip gain/complexity validation. Valid complexity also fails to reach `CeltDecoder::set_complexity`, unlike `/Users/md/language/ropus/ropus/src/opus/decoder.rs:1518`.
- **Concrete fix:** fan out through the validated `OpusDecoder` setters, reject phase-inversion values outside `0..=1`, stop at the first error, and prove CELT state changes with the wrapper state.
- **Effort:** Small, including focused CTL tests.
- **Tracked as:** `ROP-BUG-FLUX-00010`.

### Medium — multistream expert frame duration accepts invalid values

- **Confidence:** High
- **Evidence:** `/Users/md/language/ropus/ropus/src/opus/multistream.rs:1524` stores every `i32` and returns no status. `/Users/md/language/ropus/ropus/src/opus/encoder.rs:3975` correctly accepts only `OPUS_FRAMESIZE_ARG` or defined 2.5–120 ms values.
- **Concrete fix:** apply the single-stream validation before mutation and return the matching Opus status code. Add lower/upper boundary and invalid-value tests.
- **Effort:** Small.
- **Tracked as:** `ROP-BUG-FLUX-00011`.

### Medium — multistream reset retains neural PLC history

- **Confidence:** High
- **Evidence:** `/Users/md/language/ropus/ropus/src/opus/multistream.rs:2000` routes reset through `/Users/md/language/ropus/ropus/src/opus/decoder.rs:1602`. That helper resets framing, SILK, and CELT state but omits the `lpcnet.reset()` performed by the canonical reset at `/Users/md/language/ropus/ropus/src/opus/decoder.rs:608`.
- **Concrete fix:** delegate the multistream path to the canonical reset or add the same LPCNet runtime reset while preserving loaded model weights. Add a reset/reuse regression that dirties FEC, analysis, and GRU state first.
- **Effort:** Small.
- **Tracked as:** `ROP-BUG-FLUX-00012`.

### Medium — extension parsers trust counts beyond their Rust slices

- **Confidence:** High
- **Evidence:** `/Users/md/language/ropus/ropus/src/opus/repacketizer.rs:652` trusts `nb_extensions` instead of `extensions.len()` before indexing at `:675`. `/Users/md/language/ropus/ropus/src/opus/extensions.rs:104` accepts negative per-frame counts into a wrapping prefix sum; `:132` through `:136` can then cast a negative index or exceed the output slice.

## Confirmed defects

### Medium — EOS padding is emitted beyond the final granule

- **Confidence:** High.
- **Evidence:** `/Users/md/language/ropus/ropus-fb2k/src/reader.rs:487` through `:578` returns every decoded final-packet sample after leading discard, while `:918` through `:950` derives `total_samples` from the trimmed final Ogg granule. The decode path never caps output at `pre_skip + total_samples`. `/Users/md/language/ropus/ropus-fb2k/tests/roundtrip.rs:1170` through `:1191` permits a full packet after seek-to-end. RFC 7845 §4.4 requires samples beyond the EOS granule to be discarded.
- **Impact:** valid files whose source length is not a frame multiple return encoder padding beyond their advertised duration; seek-to-end can return audio instead of EOF.
- **Concrete fix:** clamp the selected stream's final packet to its absolute EOS granule, persist EOF, reject impossible granules, add a partial-final-frame fixture, and tighten seek-to-end to zero samples.
- **Effort:** Medium.
- **Tracked as:** `ROP-BUG-FLUX-00034`.

### Medium — `OpusHead` output gain is ignored

- **Confidence:** High.
- **Evidence:** `/Users/md/language/ropus/ropus-fb2k/src/reader.rs:74` through `:85` and `:1024` through `:1051` parse and store signed Q7.8 `output_gain`, but decoder construction at `:452` through `:463` never applies it. No later production path reads it, and every fixture writes zero. RFC 7845 §5.1 defines this as decode gain and says player volume adjustments apply in addition to it.
- **Impact:** valid nonzero-gain tracks play at the wrong level, independently of optional ReplayGain tags.
- **Concrete fix:** call the existing `OpusDecoder` Q8 gain setter during lazy initialization and cover positive, negative, and post-seek playback.
- **Effort:** Small.
- **Tracked as:** `ROP-BUG-FLUX-00035`.

### Medium — seek failures can corrupt or lose reader state

- **Confidence:** High.
- **Evidence:** `/Users/md/language/ropus/ropus-fb2k/src/reader.rs:688` through `:700` and `:729` through `:741` take `packet_reader`, then propagate callback-backed seek errors before restoring it. Index rollback at `:776` through `:801` ignores two abort-aware restore failures and can re-seat at the scan interruption cursor.
