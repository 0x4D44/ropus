# Fuzz replay decoder status

## Scope

Fixed ROP-BUG-FLUX-00024, where the fuzz replay tool discarded Rust-success/C-
error and Rust-error/C-success results even though the fuzz target panics on
both cases.

## Changes

- Added a pure four-quadrant `DecoderStatus` classifier.
- Stored decoder status in each replay `Finding`.
- Continue ignoring only the both-error quadrant, and emit findings for both
  one-sided decoder outcomes.
- Print the status beside every finding so replay output identifies the failure
  class.
- Added the classifier regression test.
