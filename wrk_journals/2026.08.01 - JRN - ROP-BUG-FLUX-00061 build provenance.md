# ROP-BUG-FLUX-00061 — build provenance

## Outcome

The four CLI build scripts now delegate to
`ropus-tools-core/src/build_provenance.rs`. The shared policy resolves Git's actual worktree
and common Git directory through `git rev-parse`, watches `HEAD`, the symbolic
branch ref, and `packed-refs`, and only publishes a SHA when Git's top-level
matches the workspace root that owns the package. Detached checkouts still
report their commit; packaged and vendored layouts report `unknown` instead of
leaking a consumer repository's identity.

## Evidence

- `cargo test -p ropus-tools-core --test build_provenance` — 4 passed:
  normal clone with same-branch commit refresh, linked worktree, detached
  HEAD, and vendored/packaged unknown cases.
- `cargo test -p ropusenc -p ropusdec -p ropusinfo -p ropusplay --tests` —
  25 passed.
- `cargo clippy -p ropus-tools-core --test build_provenance -- -D warnings` —
  passed.
- `cargo check -p ropusenc -p ropusdec -p ropusinfo -p ropusplay` — passed.

The workspace still emits the expected warning that optional `reference/dnn`
weights are absent; it is unrelated to provenance.
