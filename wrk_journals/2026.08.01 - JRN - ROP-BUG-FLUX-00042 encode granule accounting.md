# ROP-BUG-FLUX-00042 encode granule accounting

The encoder previously submitted only source PCM rounded to a packet boundary
and used every submitted frame as its granule position. Exact-frame inputs did
not drain encoder lookahead, while partial inputs exposed packet padding. A
960-sample fixture therefore declared only 648 playable samples after the
312-sample pre-skip. Empty input produced headers without an EOS packet.

Encoding now submits enough source-plus-silence frames to cover
`source_samples + pre_skip`. The last packet closes the stream with that exact
EOS granule, so packet padding remains encoded but is excluded from playback.
Empty decoded input fails before the destination is created.

Regression coverage decodes the produced packets, verifies the EOS flag and
granule, and proves exact and partial source lengths. The focused round-trip
suite and package clippy gate pass.
