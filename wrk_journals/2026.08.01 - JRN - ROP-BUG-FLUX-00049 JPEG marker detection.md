# ROP-BUG-FLUX-00049 — JPEG marker detection

## Change

- Changed `container::picture::detect_format` to recognise the JPEG SOI
  signature (`FF D8 FF`) without assuming JFIF, EXIF, or DQT follows it.
- Added regression fixtures for APP2 ICC-profile and APP14 Adobe marker
  layouts, plus the three-byte SOI boundary.

## Validation

- `cargo test -p ropus-tools-core --lib --no-default-features`
- `cargo clippy -p ropus-tools-core --all-targets -- -D warnings`

The repository still reports its existing warning when `reference/dnn` assets
are absent; this change does not touch neural PLC assets.
