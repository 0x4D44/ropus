# ROP-BUG-FLUX-00008 — multistream constructor bounds

Static inspection found three unchecked accesses in the multistream constructors: encoder and decoder mappings were indexed for every declared channel, and the projection constructor indexed the demixing matrix using a caller-supplied size without checking the backing slice.

The new regression test passed undersized mapping and matrix slices through `catch_unwind`; trunk reproduced a panic in `OpusMSEncoder::new_impl`. The fix validates mapping lengths, validates projection dimensions, uses checked arithmetic, and rejects demixing slices shorter than the declared byte count with `OPUS_BAD_ARG`.

Validation:

- `deltic timeout 900 cargo test -p ropus --lib --locked </dev/null` — 1879 passed.
- `deltic timeout 900 cargo test -p ropus --locked </dev/null` — 1879 unit tests and 4 doctests passed.
