# ROP-BUG-FLUX-00072 — neural PLC calibration must be like-for-like

## Observation

The classical control experiment measured 42.33 dB between C fixed-point and
C float SILK PLC. The direct neural Rust-vs-C case measured 52.21 dB, so the
classical arithmetic gap is not an upper bound for neural concealment. The
old comments and HLD amendment used that unrelated number to justify the
neural 50 dB gate.

## Change

Recast `harness-control/tests/control_snr.rs` as a diagnostic. The control now
checks the requested fixed/float mode markers and complexity, packet-stream
identity, non-silent input/output energy, expected loss count, packet-file
immutability, first divergence, and a broad 35–50 dB diagnostic interval.
The fixed and float decoder binaries announce their modes after configuration.

Add `dnn_plc_neural_cross_precision_calibration_matrix` to
`harness-deep-plc/tests/tier2_snr.rs`. It runs two deterministic fixtures
(speech-like and harmonic tone) under 7-frame and 11-frame loss intervals.
Observed SNR values were 52.21, 53.55, 51.19, and 50.63 dB. The matrix floor
is 45 dB, five decibels below the 50 dB release gate, and is independent of
the classical control result. Update the Stage 7 HLD and package description
to preserve that distinction.
