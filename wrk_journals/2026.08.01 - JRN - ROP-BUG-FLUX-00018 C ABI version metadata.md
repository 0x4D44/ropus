# ROP-BUG-FLUX-00018 — C ABI version metadata

## Scope

The C ABI exported the literal `libopus mdopus-capi-0.1.0-fixed` even though
`capi/Cargo.toml` declared version 0.2.2. This made `opus_get_version_string`
misidentify every current build.

## Change

`capi/src/lib.rs` now builds the NUL-terminated version string with
`env!("CARGO_PKG_VERSION")`, preserving the existing `libopus` and `-fixed`
format. A focused unit test reads the exported C pointer and checks both the
package version and the exact static byte representation.

## Validation

- `deltic timeout 300 cargo test -p capi --lib --locked </dev/null` — 6 passed.
- `deltic timeout 300 cargo check -p capi --locked` — passed.
- `git diff --check` — passed.

The focused commands warn that ignored reference DNN assets are absent in this
fresh worktree; the full integration gate provisions those assets before its
workspace-wide checks.
