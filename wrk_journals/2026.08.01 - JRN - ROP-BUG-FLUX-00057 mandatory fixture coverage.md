# ROP-BUG-FLUX-00057 — make required tests fail closed

## Decision

Core round-trip tests now generate deterministic 48 kHz sine WAVs (including a
stereo downmix fixture) in the system temporary directory. The ropusinfo CLI
tests generate their own WAV before encoding and leave the banner enabled for
default-mode assertions; query tests still prove typed banner suppression.

The ropusplay device test accepts only exit code 1 with the explicit `no output
devices available` error. Panics, argument failures, and enumeration errors now
fail. The DRED DTX differential is explicitly ignored because it needs optional
reference/DNN assets and a platform-independent DTX fixture; when run manually,
missing weights or an inconclusive packet search fail instead of passing.

## Evidence

- `cargo test -p ropus-tools-core --test round_trip`: 22 passed.
- `cargo test -p ropusinfo --test cli`: 7 passed.
- `cargo test -p ropusplay --test cli`: 2 passed.
- `cargo test -p ropus-harness-deep-plc --test dred_dtx_first_frame_diff`: 0
  default tests because the checkout lacks the optional reference tree; the
  differential is explicitly ignored when reference assets are present.
- Clippy passed for all four touched packages with `-D warnings`.
