# ROP-BUG-FLUX-00007 — safe DSP API

The safe public `silk_lpc_analysis_filter` entry point exposed unchecked slice
indexing to arbitrary callers. The same exposure existed on eleven other DSP
helpers that directly use `uc!`, `uc_set!`, or `uc_mut!`.

The fix makes codec-internal helpers crate-private. It retains the externally
used inverse FFT as `unsafe` with a complete contract. The public inverse MDCT
now validates its dimensions, buffers, tables, and supported FFT state before
its first unchecked access. A compile-fail doctest covers the reported LPC call,
and a unit regression covers short MDCT output.

Focused evidence:

- `cargo test -p ropus --lib`: 1,877 passed before the final MDCT regression was added.
- `cargo test -p ropus test_mdct_backward_rejects_short_output_before_unchecked_indexing`: passed.
- `cargo test -p ropus --doc`: four doctests passed, including the compile-fail regression.
- `cargo run --bin ropus-compare -- roundtrip tests/vectors/48k_sine1k_loud.wav`: roundtrip and decode-only comparisons passed for all 48,000 samples.
