# ROP-BUG-FLUX-00046 — Shared playback and transcode output gain

## What changed

- Added gain-aware shared decode entry points in `ropus-tools-core/src/audio/decode.rs`.
- Shared Opus decoding now parses `OpusHead.output_gain`, combines it with the requested user dB gain in Q8, and calls `RopusDecoder::set_gain` before decoding.
- Non-Opus shared decoding keeps the player’s prior linear f32 gain policy.
- `ropusplay --gain` now passes dB into shared decode instead of multiplying Opus f32 output after decoding.
- Added an Ogg repacking integration fixture covering zero, positive saturation, negative, user, and Opus-to-Opus transcode gain paths.

## Validation

- `cargo test -p ropus-tools-core --lib --no-default-features` — 103 passed.
- `cargo test -p ropus-tools-core --test round_trip shared_decode_applies_header_and_user_gain_for_playback_and_transcode -- --exact --nocapture --test-threads=1` — passed.
- The existing `reference/dnn` warning remains unrelated to this change.
