# Corpus diff structural validation

## Scope

Fixed ROP-BUG-FLUX-00023, where `corpus_diff` treated malformed Ogg streams and
matching decoder errors after a valid prefix as successful matches.

## Changes

- Validate every Ogg page boundary before packet decoding so a truncated tail
  cannot be hidden by `ogg::PacketReader`'s clean-EOF search behavior.
- Validate the second packet's `OpusTags` magic.
- Classify malformed streams and matching decoder errors as a distinct,
  always-non-green outcome. Exploratory skips for valid unsupported layouts stay
  separate.
- Add a `malformed` field to the corpus summary producer, parser, and HTML
  report, while keeping summary parsing compatible with older lines.
- Add missing-tags, malformed-tail, tags-magic, exit-status, and summary tests.

## Validation
