# ROP-BUG-FLUX-00052 — info query-specific collection plans

## What changed

- Parsed `--query` before opening the input and split fixed metadata, tag, and duration/bitrate collection paths.
- Fixed scalar queries now read only the OpusHead packet; tag queries stop after OpusTags; duration and bitrate use the bounded EOS granule scan and a bounded-memory decode fallback.
- Default human output no longer retains packet TOCs; extended output still does.
- Reworked raw Ogg granule collection to stream one page at a time instead of buffering the complete input.
- Moved the command-line exit-code-2 mapping for unknown query keys into `ropusinfo`, leaving the library command fallible.

## Evidence

- `cargo test -p ropus-tools-core --lib --no-default-features commands::info::tests` — 2 passed.
- `cargo test -p ropus-tools-core --lib --no-default-features container::ogg` — 26 passed.
- `cargo test -p ropusinfo --test cli -- --test-threads=1` — 7 passed.
- A bounded-reader test with a 128 KiB OpusTags comment proves the fixed header plan stops after the first page.
