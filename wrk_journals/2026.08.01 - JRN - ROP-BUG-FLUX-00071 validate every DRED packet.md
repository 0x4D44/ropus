# ROP-BUG-FLUX-00071 — validate every DRED packet

## Change

The integrated DRED acceptance tests treated one successful packet as enough.
The Rust-to-C loop ignored negative C parser returns, and the Rust self-path
stopped after its first populated extension. Later malformed or unprocessable
packets could therefore be hidden by an early success.

Added per-frame validation for both parser directions. Every packet now must
have a nonnegative C parse result or a successful Rust parse, populated
extensions must have bounded latent counts and a valid process stage, and every
populated Rust extension is processed before the loop ends. A separate flag
still requires at least one DRED-bearing packet. Pure validation tests cover a
valid packet followed by a malformed one and ordinary packets without DRED.
