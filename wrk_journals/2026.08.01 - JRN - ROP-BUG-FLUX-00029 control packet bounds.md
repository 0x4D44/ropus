# 2026-08-01 — ROP-BUG-FLUX-00029 control packet bounds

## Observation

The fixed and float control decoders cast untrusted header fields to signed
integers and `usize`, then allocated scratch and payload buffers before proving
the dimensions or packet records were valid. A four-byte length could request
gigabytes before EOF was observed.

## Fix

Both `ctrl_decode_fixed` and `ctrl_decode_float` now preflight the complete
packet file before constructing a decoder, creating the PCM output, or
allocating payload/scratch buffers. The shared contract is duplicated at each
binary boundary: Opus rates are limited to 8/12/16/24/48 kHz, channels to mono
or stereo, frame sizes to the six Opus durations, packets to 1,275 bytes, lost
records to zero payload, frames to one million, and output to 50 million
interleaved samples. Preflight uses a fixed discard buffer and rejects truncated
payloads and trailing bytes. Decode then reuses a fixed 1,275-byte payload array.

## Validation

- `cargo fmt --all -- --check`
- fixed decoder unit tests (header and packet bounds)
- float decoder unit tests (header and packet bounds)
- `cargo clippy` on both decoder binaries with `-D warnings`
- `cargo test -p ropus-harness-control --locked` (2 control SNR tests passed)
