# ROP-BUG-FLUX-00035 — fb2k output gain

## Result

The fb2k reader now applies the signed `OpusHead.output_gain` Q7.8 value by
calling `OpusDecoder::set_gain` when lazy decoder construction first occurs.
`OpusDecoder::reset` preserves the configured decode gain, so seeking does not
silently remove the header gain or apply it a second time.

## Evidence

- Added fixture builders that encode arbitrary signed `OpusHead.output_gain` values.
- Added positive and negative gain checks over full decode output.
- Added the same checks after a non-zero seek, covering decoder reset state.
- `cargo clippy -p ropus-fb2k --all-targets --locked -- -D warnings` passed.
- `cargo test -p ropus-fb2k --locked` passed (33 unit tests, 38 integration tests).

The compiler still reports the repository's existing warning that reference DNN
weights are absent in this worktree; it does not affect this crate's tests.
