# ROP-BUG-FLUX-00040 — fb2k last-error allocation

## Result

The thread-local error slot now stores `Option<CString>`. A successful entry
point clears the option and resets the status code; `last_error_ptr` returns a
static NUL string while no message is present. This removes the empty
`CString` allocation from every successful decode call.

## Evidence

- Added a steady-state pointer oracle proving repeated clears return the same
  static empty pointer.
- Existing error round-trip and FFI decode tests remain green.
- `cargo clippy -p ropus-fb2k --all-targets --locked -- -D warnings` passed.
- `cargo test -p ropus-fb2k --locked` passed (36 unit tests, 44 integration tests).

The compiler still reports the repository's existing warning that reference DNN
weights are absent in this worktree; it does not affect this crate's tests.
