# ROP-BUG-FLUX-00034 — fb2k EOS padding

## What changed

`ropus-fb2k/src/reader.rs` now retains the selected stream's absolute final
granule separately from unknown duration. `decode_next` clips each decoded
packet to the remaining EOS range, advances its absolute cursor only through
that range, and returns zero thereafter even if the final Opus packet contains
codec padding. A final granule before `OpusHead.pre_skip` is rejected as an
invalid stream instead of being hidden by saturating subtraction. Seek logic
uses the explicit EOS-known marker so known zero-length streams are not
mistaken for unknown-duration streams.

## Regression coverage

The test fixture builder can advertise an explicit final granule. The roundtrip
tests use it to verify a half-frame final packet produces exactly the advertised
PCM length, reject an impossible granule, and require `seek(total_samples)` to
return immediate EOF with zero samples.
