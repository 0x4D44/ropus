# ROP-BUG-FLUX-00020 — HTML report delivery

## Scope

`full-test` logged HTML write errors but returned the validation banner's exit
code. A PASS or WARN could therefore complete without its primary artifact.
Direct writes could also leave a partially-written report on interruption.

## Change

`full-test/src/main.rs` now routes report delivery through a small writer seam.
The production writer writes and flushes a same-directory `NamedTempFile`,
then atomically renames it to the timestamped report path. A failed write is
retained for stderr and the one-line summary, and forces exit code 1 even when
the validation banner is PASS or WARN. The JSON envelope receives that final
exit code too. CLI help and the full-test HLD document the exception.
