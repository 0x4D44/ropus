# ROP-BUG-FLUX-00012 — neural PLC reset history

Static inspection found that `OpusMSDecoder::reset` delegates to
`OpusDecoder::ms_reset`, which reset SILK/CELT and framing state but omitted
`LPCNetPLCState::reset`. That left queued FEC and neural PLC history attached
to a reused multistream decoder.

The regression loaded a synthetic PLC model, queued one FEC feature row and one
skip marker, then called `ms_reset`. Before the fix, the queue counters stayed
at one. The reset now calls `lpcnet.reset()`, clearing runtime history while
preserving the loaded model gate.

Validation:

- `deltic timeout 600 cargo test -p ropus test_ms_reset_clears_neural_plc_history --locked </dev/null` — failed before the fix, then passed after it.
- `deltic timeout 600 cargo test -p ropus multistream --locked </dev/null` — 129 passed.
- `deltic timeout 600 cargo test -p ropus decoder --locked </dev/null` — 354 passed.
- `deltic timeout 900 cargo test -p ropus --lib --locked </dev/null` — 1882 passed.
- `deltic timeout 600 cargo clippy -p ropus --all-targets --locked -- -D warnings`, `cargo fmt --all -- --check`, and `git diff --check` — passed.
