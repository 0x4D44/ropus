# ROP-BUG-FLUX-00038 — fb2k chained stream boundary

## Result

The reader now tracks the selected Ogg logical stream's EOS. It marks EOF
after returning the final selected packet and also stops cleanly if a later
chain's serial appears, so a chained `OpusHead` is never passed to the active
decoder.

Seeks and rollback reset the sticky EOS flag, allowing the selected stream to
be decoded again from a new position.

## Evidence

- Added a two-chain fixture with distinct serials and a regression asserting
  that only the first chain's post-pre-skip samples are returned.
- `cargo clippy -p ropus-fb2k --all-targets --locked -- -D warnings` passed.
- `cargo test -p ropus-fb2k --locked` passed (33 unit tests, 43 integration tests).

The compiler still reports the repository's existing warning that reference DNN
weights are absent in this worktree; it does not affect this crate's tests.
