# ROP-BUG-FLUX-00010 — multistream decoder setter validation

Static inspection found that multistream decoder gain, phase-inversion, and complexity setters wrote raw child fields and always returned `OPUS_OK`. The complexity helper updated the Opus decoder field but skipped the CELT decoder setter, leaving the two states inconsistent.

The regression passed out-of-range gain, phase-inversion, and complexity values and checked the child CELT complexity after a valid update. Before the fix, the first invalid call returned `OPUS_OK`; after the fix, all invalid values return `OPUS_BAD_ARG`, while valid complexity updates both decoder layers.

Validation:

- `deltic timeout 600 cargo test -p ropus decoder_setters_validate_and_update_celt --locked </dev/null` — failed before the fix, then passed after it.
- `deltic timeout 600 cargo test -p ropus multistream --locked </dev/null` — 128 passed.
- `deltic timeout 900 cargo test -p ropus --lib --locked </dev/null` — 1880 passed.
- `cargo clippy -p ropus --all-targets --locked -- -D warnings`, `cargo fmt --all -- --check`, and `git diff --check` — passed.
