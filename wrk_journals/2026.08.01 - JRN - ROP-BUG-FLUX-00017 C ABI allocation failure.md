# ROP-BUG-FLUX-00017 — C ABI allocation failure

## Scope

Fixed the C ABI constructor paths that previously called `handle_alloc_error`
or used infallible wrapper allocations. The change covers single-stream,
multistream, projection, and repacketizer create/init entry points.

## Implementation

- Added `capi/src/alloc.rs` with fallible zeroed allocation, boxed-value, and
  vector-capacity helpers.
- Staged inner Rust state and multistream sub-handles before publishing the C
  handle. Partial sub-handle allocations are released on failure.
- Delayed projection and surround encoder output parameters until all staged
  allocations succeed.
- Added test-only allocator failpoints covering single-stream failure,
  multistream partial setup, and projection output-parameter atomicity.

## Validation

- `cargo check -p capi --locked`
- `cargo test -p capi --lib --locked` — 5 passed
- `cargo test -p capi --test ms_decoder_ctl --locked` — 1 passed
- `git diff --check`

The worktree does not contain the ignored reference/DNN assets, so the full C
conformance harness was not run here.
