# ROP-BUG-FLUX-00069 — finite neural differential oracles

## Change

The RDOVAE encoder and decoder differential tests and the LPCNet feature-drift
report compared f32 values without checking finiteness first. Equal NaNs could
look bit-exact, while NaN drift and SNR values bypassed ordered updates and left
the initial positive-infinity Tier 2 score unchanged.

Added `tests/support/finite_oracle.rs`, which rejects non-finite inputs and
paired outputs with an indexed diagnostic. The three neural oracles now invoke
it before bit comparisons and SNR/drift calculations, and reject non-finite
derived SNR/RMS metrics. Regression tests cover finite controls, shared NaN,
one-sided NaN, and positive/negative infinity. Existing LPCNet helper coverage
also runs against the fetched C reference fixture.

- `cargo test -p ropus-harness-deep-plc --test dred_lpcnet_feature_drift -- --nocapture </dev/null`

All focused neural differential tests passed with the C reference and DNN
weights present; each reported bit-exact output on its deterministic oracle.
