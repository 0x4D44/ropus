# ROP-BUG-FLUX-00039 — fb2k OpusTags field names

## Result

The OpusTags parser now validates every comment key byte against the Vorbis
field-name grammar: ASCII `0x20..=0x7D`, excluding `=`. A typed `InvalidKey`
error rejects controls and non-ASCII UTF-8 before normalization or metadata
callbacks.

## Evidence

- Added parser unit tests for newline/control and non-ASCII field names.
- Added FFI integration coverage proving malformed tags return
  `ROPUS_FB2K_INVALID_STREAM`.
- `cargo clippy -p ropus-fb2k --all-targets --locked -- -D warnings` passed.
- `cargo test -p ropus-fb2k --locked` passed (35 unit tests, 44 integration tests).

The compiler still reports the repository's existing warning that reference DNN
weights are absent in this worktree; it does not affect this crate's tests.
