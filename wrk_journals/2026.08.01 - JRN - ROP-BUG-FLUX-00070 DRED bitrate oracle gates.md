# ROP-BUG-FLUX-00070 — DRED bitrate oracle gates

## Change

The original bitrate-plumbing test was named as byte parity but only compared
the TOC byte and a 20% cumulative packet-size envelope across fixed-point Rust
SILK and float-mode C SILK. It could not prove DRED activity. The nonzero test
also judged ordinary PCM SNR without parsing either packet stream.

The coarse test is now explicitly labelled as a cross-precision SILK envelope
diagnostic. The scalar differential pins the integrated duration-100,
16 kHz/40 kbps/loss-30 configuration and has a dedicated assertion that both
bitrate and target-chunk outputs are nonzero. The active packet test parses all
Rust and C packets with `OpusDREDDecoder`, requires a populated extension in
each stream, then performs its PCM SNR check.
