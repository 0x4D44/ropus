# ROP-BUG-FLUX-00051 — Terminal control sanitization

## Change

- Added the shared `ui::escape_terminal_text` / `escape_terminal_path` policy
  for C0/C1 controls, Unicode line separators, bidi overrides, and reversible
  backslash escaping.
- Applied it to human-facing info, encode, decode, playback, device-list,
  status-line, warning, path, and error-chain output.
- Kept `ropusinfo --query vendor/comment:*` raw only when stdout is redirected;
  terminal queries escape controls. Device listings use the reversible escaped
  form while `--device` matching still uses the exact raw cpal name.
- Added deterministic tests for C0/C1, OSC/BEL, CR/LF, bidi, path, status,
  query, and device-name cases.

## Validation

- `cargo test -p ropus-tools-core --lib --no-default-features`
- `cargo clippy -p ropus-tools-core -p ropusenc -p ropusdec -p ropusplay --all-targets -- -D warnings`
- `cargo test -p ropus-tools-core --test round_trip -- --test-threads=1`
- `cargo test -p ropusenc -p ropusdec -p ropusplay`

The repository still reports its existing warning when `reference/dnn` assets
are absent; this change does not touch neural PLC assets.
