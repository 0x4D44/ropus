# ROP-BUG-FLUX-00045 — OpusHead parser validation

## What changed

- `container::ogg::parse_opus_head` now accepts only compatible OpusHead
  versions (major nibble zero), mono/stereo output, mapping family 0, and the
  exact 19-byte family-0 header shape.
- `audio::decode::decode_reader` now sends Symphonia's OpusHead extra data
  through the same parser before constructing the decoder, so playback and
  transcode cannot bypass the validation.
- Added parser coverage for valid minor versions plus a malformed-header
  matrix covering magic, version, channels, mapping family, length, and short
  packets.

## Validation

- `cargo test -p ropus-tools-core --test round_trip -- --test-threads=1` (20 passed)
- `cargo test -p ropus-tools-core --lib` (103 passed)
- `cargo clippy -p ropus-tools-core --all-targets -- -D warnings`

The existing warning about missing `reference/dnn` assets remains; this change
does not add Rust warnings.
