# 2026-07-30 — macOS / ARM optimisation

## Goal

Make macOS on Apple Silicon a measured, bit-exact performance target:

- build the C comparison oracle correctly on AArch64;
- use a conservative Apple-Silicon compiler baseline;
- profile the fixed-point codec on Apple Silicon;
- complete only the safe SIMD kernels justified by evidence;
- preserve identical codec output and the existing cross-platform fallback.

Raw `std::arch::aarch64` intrinsics, a new dependency, internal codec
threading, and floating-point reassociation are out of scope unless the
evidence exposes a blocker that cannot be solved through the existing `wide`
dependency or compiler-friendly safe Rust.

Residual risks at checkpoint:

- x86 source selection can be cross-compiled locally, but a fleet x86 runtime
  may not be reachable from this Mac; missing runtime evidence will be stated
  rather than hidden.
- Upstream ARM/scalar and x86 SSE disagree at the already-documented
  `celt_fir` negative saturation edge. This work preserves existing ropus
  output and treats the difference explicitly.
- Candidate SIMD work may be rejected if focused timings do not clear noise.
