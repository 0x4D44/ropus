# ROP-BUG-FLUX-00037 — fb2k duration scan

## Result

The reverse duration scan now validates each candidate's complete page extent,
reserved header flags, selected stream serial, Ogg CRC, and EOS flag before
using its granule. Header-shaped bytes inside an Opus payload no longer replace
the actual final page's duration.

## Evidence

- Added an integration fixture that embeds an EOS-looking, bad-CRC header in
  the real final page payload and recalculates the real page CRC.
- The fixture still reports the real packet-count-derived duration.
- `cargo clippy -p ropus-fb2k --all-targets --locked -- -D warnings` passed.
- `cargo test -p ropus-fb2k --locked` passed (33 unit tests, 42 integration tests).

The compiler still reports the repository's existing warning that reference DNN
weights are absent in this worktree; it does not affect this crate's tests.
