# ROP-BUG-FLUX-00047 — Reverse Ogg duration validation

## What changed

- Replaced the tools-core reverse duration scan's header-only acceptance with a complete page validator.
- Candidates now require Ogg version 0, reserved flags clear, selected stream serial, complete lacing/payload extent, valid CRC, and EOS before their granule is trusted.
- `ropusinfo` now rejects a final granule or slow decoded count below `OpusHead.pre_skip` instead of saturating to zero.
- Added parser tests for valid pages, unknown granules, wrong serials, non-EOS trailers, bad CRCs, truncated pages, and fake `OggS` bytes inside payload data.

## Validation

- `cargo test -p ropus-tools-core --lib` — 107 passed.
- `cargo test -p ropus-tools-core --test round_trip -- --test-threads=1` — 21 passed.
- `cargo clippy -p ropus-tools-core --all-targets -- -D warnings` — clean.
- The existing `reference/dnn` warning remains unrelated to this change.
