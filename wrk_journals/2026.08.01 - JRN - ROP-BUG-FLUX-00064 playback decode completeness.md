# ROP-BUG-FLUX-00064 — playback decode completeness

## Outcome

The shared decoder now rejects an empty decoded sample vector after Opus EOS
and pre-skip trimming. This covers streams with no audio packets, streams
whose packets all fail decode, and valid packets entirely consumed by
pre-skip. Playback receives an error instead of appending an empty sink, so
its existing consecutive-error handling terminates single-track Off, All, and
Single loops rather than reporting successful playback.

## Evidence

- `cargo test -p ropus-tools-core --tests` — 133 unit tests, 4 build-provenance tests, 23 round-trip tests, and doc-tests passed.
- `cargo clippy -p ropus-tools-core --tests -- -D warnings` — passed.
- The new round-trip fixture covers header-only, all-invalid, and pre-skip-only
  streams; the pre-skip case asserts the new `no audio samples` failure.

The checkout still emits the expected warning that optional `reference/dnn`
weights are absent; it is unrelated to playback completeness.
