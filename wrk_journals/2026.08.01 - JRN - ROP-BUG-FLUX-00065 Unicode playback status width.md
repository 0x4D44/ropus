# ROP-BUG-FLUX-00065 — Unicode playback status width

## Change

`ropus-tools-core/src/commands/play.rs` now measures status prefixes, labels,
and suffixes in terminal display cells with `unicode-width`. Label truncation
uses `unicode-segmentation` grapheme clusters, reserves one cell for the
ellipsis, and stops at the first cluster beyond the visible budget. The
startup decoding progress line uses the same width policy.

The direct dependencies are recorded in `ropus-tools-core/Cargo.toml` and
`Cargo.lock`. This avoids scalar-count overflow for CJK and emoji labels and
avoids splitting combining sequences or emoji ZWJ clusters. The pure status
line tests cover wide labels, combining marks, emoji, narrow terminals, and a
resize from 120 to 40 columns.
