# ROP-BUG-FLUX-00016 — Multistream decoder complexity CTL

## Finding

The Rust `OpusMSDecoder` already exposed `set_complexity` and `get_complexity`, but the C varargs switch omitted request codes 4010 and 4011. The typed Rust multistream decoder dispatcher also had no matching arms, so both public C calls returned `OPUS_UNIMPLEMENTED`.

## Reproduction

Added a typed-dispatch regression and a C-variadic integration test. Before the dispatcher change, a valid complexity setter fell through to the unimplemented arm. The tests cover setting complexity to 7, reading it back, and rejecting -1 and 11 without changing the previous value.

## Fix

The C shim now routes `OPUS_SET_COMPLEXITY` and `OPUS_GET_COMPLEXITY` for multistream decoders. The Rust setter validates `0..=10` before fanning out to every stream, then the getter returns the first stream's value, matching the multistream API contract.
