# ROP-BUG-FLUX-00026 benchmark trace isolation

The benchmark linked trace instrumentation into both implementations. The
`ropus-harness` dependency always enabled Rust's `trace-silk-encode` feature,
whose process-global tuple buffer grows without a bound. The C reference build
also replaced Xiph's normal `silk/enc_API.c` with the traced harness copy.

Tracing is now an opt-in harness feature required by the two trace diagnostic
binaries. Default comparison and benchmark builds compile normal Rust and Xiph
encoder paths. The benchmark also asserts the codec dependency's actual feature
state, so Cargo feature unification cannot silently restore Rust tracing.

Focused proof covered the default benchmark, rejection of harness-enabled and
dependency-unified trace builds, both diagnostic binaries, and the trace tuple
positive control.
