# ROP-BUG-FLUX-00019 — Stage 2 Cargo status

Stage 2 discarded `std::process::Output.status` after capturing Cargo output.
The text parser therefore returned zero failures when Cargo exited nonzero
without a recognized compiler diagnostic or complete libtest summary.

The fix retains a structured Cargo termination classification. A nonzero exit,
signal, or status-less termination becomes a Stage 2 build/execution failure
only when parsed output has not already explained the failure. Existing test
failure and compiler-failure classifications remain unchanged.

Regression evidence:

- Before the fix, the injected nonzero-empty, nonzero-unrecognized, and signal
  cases failed while the successful-summary control passed.
- After the fix, `cargo test -p full-test` passed all 230 tests.
- The tests cover Unix `ExitStatus` signal mapping and confirm a recognized
  failed-test summary remains a test failure rather than a build failure.
