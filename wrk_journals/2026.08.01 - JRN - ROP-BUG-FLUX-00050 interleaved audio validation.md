# ROP-BUG-FLUX-00050 — Interleaved audio validation

## Change

- Downmix and resampling now reject interleaved buffers whose sample count is
  not divisible by the channel count instead of silently dropping the tail.
- Both WAV writers validate non-zero rates/channels, complete frames, and
  checked block-align, byte-rate, data-size, and frame-count arithmetic before
  creating a file or writing a header.
- Added malformed-shape and overflow regression tests for all three helpers.

## Validation

- `cargo test -p ropus-tools-core --lib --no-default-features`
- `cargo clippy -p ropus-tools-core --all-targets -- -D warnings`

The repository still reports its existing warning when `reference/dnn` assets
are absent; this change does not touch neural PLC assets.
